O Problema

IA decide. Humano assiste.
Isso nao e governanca.

O mundo esta delegando decisoes criticas para modelos de IA sem qualquer mecanismo formal de supervisao e responsabilizacao.

⚠

IA aprova sem responsavel

Pipelines automatizados executam acoes de alto impacto sem registro auditavel de quem validou e por que.

📋

Sem prova juridica de conformidade

Em caso de litigio, como provar que um humano revisou a proposta antes de ela ser executada?

🔓

SLAs sem custodia formal

Janelas de decisao abertas indefinidamente. Inercia aprovando por omissao. Sem carimbo de data/hora probatorio.

Passo a Passo

Como utilizar o Calice

Do primeiro payload ao selo institucional verificavel em 6 etapas claras.

01
📨
Interceptar uma Proposta

Envie o payload da IA para o endpoint de interceptacao. O motor avalia confianca do modelo, clausula de responsabilidade e regras da politica do cliente. Se houver violacao, o Fator de Pausa e ativado imediatamente.

// POST /api/v1/intercept
{ "document_id": "DOC-2026-001",
  "confidence_score": 0.70,
  "prazo_customizado_segundos": 1800 }
02
🔐
Autenticar como Operador

Apenas operadores com conta ativa podem decidir. A autenticacao e feita com scrypt + bearer token. Contas sao criadas via CLI com o comando abaixo.

// Criar conta:
python main.py operador criar <login> "Nome"
// POST /api/v1/auth/login
03
⚖
Revisar o Diagnostico

O console exibe as violacoes detectadas, o score de confianca do modelo, a janela de SLA com cronometro em tempo real. O operador declara ciencia explicita de cada violacao antes de decidir.

// No Console em http://127.0.0.1:8000
Confianca: 0,70 (min: 0,85)
Lacuna juridica detectada | 29:45 restantes
04
🏛
Chancelar ou Rejeitar

Com justificativa obrigatoria (minimo 15 caracteres) e ciencia declarada de todas as violacoes, o operador chancela. O silencio nunca aprova por omissao. Sem decisao, a proposta fica travada.

// POST /api/v1/seal
{ "transaction_id": "TX-...",
  "notes": "Auditado e aprovado...",
  "acknowledged_violations": [...] }
05
🔏
Verificar o Selo Institucional

Apos a chancela, e emitido um Selo CLC-AUTH em Base58 com HMAC-SHA256 e assinatura Ed25519. Qualquer auditor pode verificar o livro-razao publicamente, sem acesso a chave secreta.

// GET /api/v1/ledger/verify
CLC-AUTH::TX-20260930-...::20260930...::De6BM...
// python verificar_publico.py
06
🚀
Integrar via API ou CLI

Use a bancada de estresse para teste concorrente, o roteiro demo_fluxo.py para demonstracao de ponta a ponta, ou integre diretamente via REST com payloads em portugues ou ingles.

python demo_fluxo.py
python bancada_concorrente.py
python main.py estresse --eventos 100
Funcionalidades

Uma plataforma de governanca completa

🔗
Livro-razao Duplo Encadeado

Cada evento e encadeado com HMAC-SHA256 e assinado individualmente com Ed25519. Adulteracao de qualquer registro invalida toda a cadeia subsequente.

Probatorio
⌛
SLA com Inercia Zero

Cada proposta recebe um prazo definido. Esgotado o tempo sem decisao humana, o sistema lavra automaticamente o decurso do prazo. O silencio nunca aprova.

Human-in-the-loop
🎯
Politicas por Cliente e Operacao

Defina limiares de confianca, prazos e acoes no esgotamento por cliente (ex: CLI_1029) e canal de operacao (FINANCEIRO_PIX, CONTRATOS_JURIDICO).

Multi-cliente
🌊
Streaming sob Custodia

O CaliceEngine monitora a geracao de IA em tempo real chunk a chunk. Quando o score cai abaixo do limiar, a geracao e interrompida e registrada no livro imediatamente.

Tempo real
🔄
WebSocket de Eventos ao Vivo

O console web se mantém atualizado em tempo real via WebSocket. Novos eventos de interceptacao, chancela, rejeicao e timeout sem necessidade de polling.

Reativo
⚡
Concorrencia com Integridade

Transacoes atomicas BEGIN IMMEDIATE no SQLite com WAL. Disparos de 10 requisicoes simultaneas processadas sem quebra de cadeia de hashes.

Alta disponibilidade

A API aceita payloads com nomes de campos em portugues ou ingles. Todos os endpoints retornam JSON estruturado e emitem eventos WebSocket em tempo real.

POST/api/v1/interceptInterceptar proposta
POST/api/v1/sealChancelar e selar
POST/api/v1/rejectRejeitar proposta
GET/api/v1/ledger/verifyVerificar integridade
GET/api/v1/ledger/exportExportar livro
POST/api/v1/auth/loginAutenticar operador
POST/api/v1/policiesCriar politica
WS/api/v1/ws/eventsEventos ao vivo
python main.py   # inicia em http://127.0.0.1:8000
Prova Criptografica

Probatorio por design.

Cada decisao gera uma trilha de auditoria imutavel verificavel por terceiros sem acesso a chave secreta.

🔐

HMAC-SHA256

Cada bloco carrega o HMAC do bloco anterior. Alterar qualquer registro invalida toda a cadeia subsequente.

Encadeamento Criptografico
✍

Assinatura Ed25519

Cada evento e assinado individualmente com chave privada Ed25519. A chave publica pode ser distribuida a auditores para verificacao sem exposicao do segredo.

Autenticidade Publica
🎅

Selo CLC-AUTH em Base58

O Selo Institucional Oficial e emitido em formato CLC-AUTH::TX::timestamp::token com referencia a transacao e carimbo de tempo.

Verificacao Publica
🌎

Auditoria por Terceiros

O script verificar_publico.py permite que qualquer auditor verifique toda a cadeia do livro-razao usando apenas a chave publica.
